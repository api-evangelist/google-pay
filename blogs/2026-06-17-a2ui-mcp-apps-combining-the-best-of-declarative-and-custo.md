Shows how developers can integrate Agent-to-User Interface (A2UI) with Model Context Protocol (MCP) Apps to balance customization and seamless integration in agentic workflows. It presents three architectural patterns: A2UI over MCP servers for native component rendering, embedding MCP Apps within A2UI components, and running A2UI inside MCP Apps for legacy modernization, with a decision tree to pick the right approach.
